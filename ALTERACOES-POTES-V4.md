# Potes V4 — visual premium fosco

- Arcos de progresso contínuos no lugar dos segmentos, com animação suave.
- Gradientes dos símbolos SVG ajustados para verde-esmeralda, creme, grafite e dourado fosco.
- Sombras reduzidas, cores menos saturadas e microinteração discreta.
- Mantidas as regras de cálculo, persistência, aportes, despesas, patrimônios e navegação.

**Nota:** os ícones atuais são SVG vetoriais do projeto com nova paleta e acabamento. Esta versão não inclui novos modelos 3D renderizados individualmente.
